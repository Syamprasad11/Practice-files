# Python Calculator Programs

A collection of simple Python programs created to practice basic programming concepts.

## Programs

- **Factorial Calculator** – Calculates the factorial of a given number.
- **Grade Calculator** – Calculates a student's grade based on their marks.
- **Prime Number Calculator** – Checks whether a given number is a prime number.

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the required Python file:

```bash
python filename.py
